- 原始 DOM 资源清单与截图保存在项目 work/cqu-atlas-match/reference-assets.json 和 reference-*.png。

这些参考资产的公开重用许可未确认；本次只保存在本地原型，没有对外部署。人物照片沿用本项目已归档的校方资料，未复制重庆大学人物肖像或校徽。
