# 李承三 · 山川为卷

独立的 React 数字人物展览，版本 3.0。只涉及李承三专题；不替换现有学者页面或站点路由。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

构建目录为 `dist/`，Vite 使用相对资源路径，可整体放到任意静态子目录。建议在原仓库新增 `previews/chengsan-deepbook-v3/`，不要覆盖 `previews/chengsan-v8/`。

独立 HTML：完成构建后运行 `node scripts/build-standalone.mjs`，得到上一层的 `李承三-山川为卷-展览版.html`。脚本、样式、数据、图片和字体均嵌入；出处链接需联网。浏览器需要启用 JavaScript，装饰性 Silk 背景可在不支持 WebGL2 时退化为静态背景。

## 与原项目的关系

参考仓库 `Ppzh-Wick/normal`，检查时 main 为 `192b783dbeb9db916d3439ce4f38703a14d98102`。其中当前 v8 预览为编译产物，`scholar-studio` React 源码较旧，不能假设二者一致。本项目是隔离的新 React 实现，没有编辑旧压缩 bundle。应作为独立目录或独立静态页面接入，避免把全局样式直接注入旧应用。原 v1/v2 文件保留。

## 阅读与交互

七章：序章、一生、学脉、手迹、传承、档案、出处。人物介绍先于关系图。

- 桌面一轮滚轮手势前进或后退一章。长内容先读完本章，再以新的手势翻章。
- 提供上一屏/下一屏、章节目录、键盘 PageUp/PageDown、自由滚动模式。Escape 可退出逐屏模式；在详情/图片弹窗内先关闭当前内容。
- 图谱保留24条关系，全部24条完整展开；分类可筛选、搜索、分组、切换列表、缩放/平移。节点位置和大小不表示亲疏或影响力。
- 节点有具体关系记述、时间、页码和资料出处；原始图像来源与文字依据分开。
- 手迹查看器可放大并滚动，保留原图标记；放大不创造新细节。
- 档案包括生平、29条年谱、14个地点、19项著述、17幅图像、3项报道。支持检索、排序、阶段筛选、地址状态、浏览器本地收藏和JSON导出。
- 窄屏改用自然滚动与关系列表。尊重减少动态偏好，采用有限时长入场动态，不提供可见暂停按钮。
