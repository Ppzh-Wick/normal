# 山河之间 · 李承三数字人物展

独立的 V5 地层叙事实验展。以大胆的展览式编排呈现李承三的生平、调查、教学及学术交往，同时保留可核对的文字依据和图像出处。人物介绍在24节点关系图之前，视觉演绎不替代历史材料。

本目录从已优化 V4 基线独立复制；本轮实验不修改 V3、冻结 V4、深化候选或性能发布目录，也不替换其他学者页面、站点主页或旧预览。仓库接入应采用独立源码目录和独立预览目录，具体路径、提交和发布状态待发布任务确认。此说明不代表已经上线。

## 本地运行

在本目录运行，使用 Node.js 20.19+ 或 22.12+：

```sh
npm install
npm run dev
```

其他已有命令：

```sh
npm test
npm run build
npm run preview
```

这些命令对应本目录的 `package.json`。开发与预览服务默认绑定 `127.0.0.1`，实际地址以终端输出为准。构建产物在 `dist/`；构建脚本使用相对资源路径，可作为独立静态子目录部署。

## 单文件 HTML

先构建，再运行现有脚本：

```sh
npm run build
node scripts/build-standalone.mjs
```

脚本输出至项目目录的上一层：`../李承三-山河之间-地层叙事实验.html`。这里不是 `npm run standalone`，当前应直接执行上述 Node 脚本。

脚本从 `dist/` 和 `public/` 读取资源，把已引用的脚本、样式、图片和字体嵌入 HTML，并检查未解决的运行时导入与资源引用。它还会更新 `scripts/standalone-report.json` 和 `README-standalone.md`。源站与文献链接保留为外部链接，打开时仍需联网。

阅读需要启用 JavaScript。V4 的装饰地形使用 Canvas 2D，不依赖 Silk 或 WebGL2。单文件能否直接通过 `file://` 打开，应以最终浏览器验收为准，不能用脚本检查代替实际打开测试。本交付不生成 ZIP。

## 阅读路径

七章依次为：山河之间、走近其人、一纸山川、学脉相连、所见所传、档案深处、有所依据。

- **先认识人，再进入图谱。** 人物介绍提供求学、调查与育人三条线，以及可切换的人生节点。
- **读一张手绘图。** 从地名、线条与图幅编号观察嘉陵江图集第24号图；可查看完整原图和出处。讲解仅解释可见内容，不推断图中岩层年代。
- **跟随第24号图。** 可选择一条阅读线索，依次查看考察关系、1946成果题录和两类出处；随时结束，不强制完成。
- **24条关系一起展开。** 径向总览默认展示全部关系，提供关系词显隐、分类、搜索、列表阅读、缩放及平移。选择节点后显示具体记述、年份和依据；位置、远近与节点大小不表示亲疏或影响力。
- **从研究走向教学。** 现场观察、成果整理与指导后学分别呈现，并可回到对应关系记录。
- **六类档案直接进入。** 索引通向29条年谱节点、19项著述题录、17幅影像文献、4章生平、14个地点和3项纪念／报道。年谱是选编，不是原PDF全部条目的逐字转录。
- **继续查阅。** 阅览室提供年谱阶段筛选、地点索引、著述检索／分类／排序、图像查看和出处链接。收藏保存在当前浏览器，JSON下载包含整理数据和来源说明，不等同于下载原始文献。

## 导航与可访问性

以下为当前实现；实际验收范围与限制见 VERIFICATION.md：

- 桌面提供逐屏展览和自由阅读两种模式、章节目录及上一屏／下一屏按钮；长章节允许先阅读章内内容。
- 逐屏模式提供 PageUp／PageDown 等键盘操作；Escape 可退出逐屏模式，弹窗开启时优先处理弹窗关闭。
- 有跳至人物介绍的链接、语义标题、图片替代文字、可聚焦的关系节点、原生弹窗和关闭后的焦点返回逻辑。
- 人生节点及档案栏目支持键盘切换；图谱提供不依赖图形空间布局的列表入口。
- 窄屏采用自然滚动；图谱与列表入口仍然保留。不能把响应式实现当作已完成真机测试。
- 尊重 `prefers-reduced-motion`。标题和地形采用有限时长入场效果；装饰画布不承担独有的文字信息。

## 深化阅读交互

本轮把空间变化用于阅读，而非增加无关装饰：

- 手绘图从展陈状态进入同一原图的讲解状态；桌面可开启原像素2倍观察镜，方向键移动、Escape退出。
- 选择关系后，图谱保留在左侧，右侧展开可滚动的史料页。当前联系自动聚焦，可恢复全图、继续平移缩放或切换列表；关闭后返回原有视角。初始总览仍为24个圆形节点及连线。
- 影像栏目用稳定目录控制17件材料的主展位。选择图片进入平面阅览室，返回时保留原条目及焦点。
- 支持原生 View Transition 的浏览器可看到原物件的连续变换；不支持或偏好减少动态时，阅读功能仍直接可用。


## V5 地层叙事，2026-11-04 UTC

本轮原创视觉把抽象地形、真实手绘图与学术关系放在同一条阅读线上。三个静态地层切片托起第24号图；点击历史图片直接开始原有的可追溯阅读线索。人物章、原图章与图谱章复用低密度抽象等高线；桌面章节标尺提供可直接跳转的七章入口。历史数据与 public 资产逐字节保持不变。
