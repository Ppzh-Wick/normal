# Mineral material poster

mineral-grain.webp is an abstract decorative material, not a historical image or geographic reconstruction. It was rendered from the actual React Bits Grainient shaders at upstream revision 4dc7b5b7772e1217c8fb8d2a7aa074302180e5b4, using this exhibit's configured palette.

Rendered with existing Mesa EGL / llvmpipe CPU software rasterization at 960×600, then encoded as WebP. It is the static fallback for mobile, reduced-motion, and unavailable WebGL. This is not evidence of live browser GPU rendering or physical-device performance.
