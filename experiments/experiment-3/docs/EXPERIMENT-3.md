# 实验3 · 关系回响

独立的动效探索版，基于已保存的实验2聚焦版本。实验2及原作业不覆盖。

## 动作节奏

- 选中关系：只让这条关系短暂描线，再给所选节点一圈淡回响，文字依据连线接到纸面。
- 证据正文：轻微展开后完全静止，关闭按钮始终保持原位可用。
- 章节切换：复用既有取消、历史和焦点管理，在支持 View Transition 的浏览器上做有限的双快照纵深切换。
- 手机：图谱初次进入时居中，省去关系光效，只保留极短纸面透明度变化。
- 减少动态：不播放新增动效；所有史料仍可直接阅读。

新增关系动效为原创 WAAPI/SVG 实现，并非 Active Theory 或 React Bits 的代码。既有 React Bits 组件的来源、改动和许可仍见 licenses/ 与原有文档。背景、24条关系、分类、史料与图像保持原样。

最长一次新增关系动作720ms，操作、离开章节、隐藏标签页或打开减少动态时会取消。控制器在完成后释放动画对象，不保留填充层。桌面其他节点继续轻微虚化，手机只降透明度。

## 验证

运行 npm test、npm run build 后，使用 Playwright Chromium 执行 scripts/verify-pair-focus.mjs 及 scripts/verify-relation-motion.mjs。前者覆盖原24节点、分类、聚焦恢复、键盘和手机，后者检查动作真实出现、完成、取消和静止期成本。最终结果以CI日志及浏览器截图为准。

不把无GPU的CI浏览器结果当作实体手机或Safari性能结论。
