# 山河之间 · 群青与辰砂

独立 V6 配色实验，基于已优化 V5 的全部内容、交互与性能策略。与 V5、V4、作业版和站点主页分开，不覆盖任何旧版。

## 本地运行

Node.js 20.19+ 或22.12+。运行 `npm install`，再用 `npm run dev`。自动检查：`npm test`；静态构建：`npm run build`；独立HTML：`node scripts/build-standalone.mjs`。

构建输出 `dist/`，资源为相对路径，适合独立子目录部署。独立HTML输出 `../李承三-山河之间-群青辰砂实验.html`，不会覆盖前版。

## 配色与阅读

- 首屏与图谱：深群青、明亮钴蓝地层、骨白文字；辰砂色用于当前章节、阅读路径与激活关系。
- 原图章：暗酒红衬托未经重绘或染色的历史纸张，阅读纸页回到暖白。
- 人物与档案章：干净骨白，深蓝正文；大门和编号用冷暖颜色建立层级。
- 研究教学章：深紫、暖白、深蓝三层对应现场、成果、课堂。

颜色只承担展示和操作层级，不表示地质年代、真实地形或人物关系强弱。图谱默认全部24圆形节点，分类、列表、来源和图像原件保持。人物介绍仍位于关系图前。

## 性能与可访问性

本轮没有增加动画、RAF、事件监听或第三方依赖。保留有限时长入场、缓存地形、离屏与后台暂停、拖动批处理、移动自然滚动和减少动态降级。关键文字色对经自动对比度检验；历史图像不施加新的滤镜。46项测试以及实际浏览器验收见 V6-VERIFICATION.md。
