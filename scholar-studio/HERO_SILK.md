# 酒红丝绸首屏 · v26

2026-10-21，当前分支 `design/plum-silk-hero`。本地保存，按用户约定暂停 GitHub 同步。

## 当前设计

全幅 React Bits Silk、左下大标题、本地 Noto Sans SC 可变字体和玻璃探索按钮。首屏使用石榴红 `#853039`、暖色高光 `#c9a394`、红黑底色 `#180c0f`、暖白文字 `#f7f2ef`。首屏导航光边使用暖红与暖白，滚动后的共享导航样式保留。

Silk 参数：speed 2.4、scale 1.2、rotation 0.25、noiseIntensity 0.3、sheen 0.42、depth 0.62、glow 0.01、ripple 1.1、wave 0.8、variation 0。关闭鼠标扭曲、点击波纹与组件 intro，由既有 GSAP 统一揭幕。

组件会再以0.1缩放speed。初版0.48在实际浏览器运行但视觉变化过慢，按用户反馈调到2.4。首屏打开后无需悬停就持续流动；离屏、页面隐藏、系统减少动态效果时暂停，返回后恢复。保留 DPR 1、30fps与100万像素上限。首屏手动暂停按钮已移除；人物墙暂停按钮独立保留。

仅首屏调色与调速。四行十三人人物墙、Lightfall、分组、独立人物页、返回状态、项目与学者优势尚未在v26重排。
