# 性能审查与预算

日期：2026-10-20。范围：图片与视频、WebGL 背景、滚动事件、GSAP、首屏资源。

## 图片与视频

- 首图四档 WebP：800px 45,292 B；1600px 166,368 B；1920px 237,094 B；2560px 440,862 B。边缘柔化使用 400px、8,656 B 的独立装饰图。
- HTML 中预加载与 React 中 srcSet / sizes 一致，浏览器检查确认首图只请求一次；主图 high 优先级，柔化层 low 优先级，两层均异步解码。
- 八张肖像合计 19,193 B，三张专题 SVG 合计 7,289 B，保留现有质量；专题图片继续懒加载。
- 旧校园 MP4 为 433,717 B，旧海报为 73,545 B。当前页面没有 video 元素、也没有视频网络请求。这两项及原 JPEG 从 dist 排除，源码保留原件。

## WebGL

- Grainient 与 Lightfall 分别懒加载；首图解码后再择空闲时间初始化首页背景，学者区真正进入视口才加载 Lightfall。
- 修复了只接触视口边界、可见面积为零时仍持续绘制的情况。判断可见面积并增加微小阈值，初始不可见状态不执行绘制。
- 装饰背景最多每秒绘制 30 帧，单画布最多 150 万像素，画面以原比例填满容器。前景 GSAP 与人物轮播不受此帧率预算限制。
- Lightfall 仍保留四级 bloom；纹理分配改为只在尺寸改变时执行，bloom 纹理使用预算后的尺寸。每帧缓存尺寸、颜色与调色板；鼠标事件先合并，再随渲染帧读取坐标。
- 学者区完整覆盖视口时暂停 Grainient。页面隐藏和离屏时取消待执行帧；恢复可见时继续。减少动态效果时只绘制静态背景。
- 无 WebGL2 时用既有 CSS 背景承接，内容与轮播可继续操作；非关键背景分块加载失败有错误边界兜底。

## 滚动与 GSAP

- 导航 scroll 监听保持 passive，经 requestAnimationFrame 合并；只有跨过悬浮阈值才更新 React 状态。阈值在 ResizeObserver / resize 中测量。
- BorderGlow 的全局复位监听由所有卡片共用，颜色变量缓存，指针移动仍合并到帧内更新。
- 保留 opening、遮罩揭开、卡片错峰及轻微视差。单次入场结束后清除临时 transform / clip-path；断点变化及减少动态效果通过 matchMedia 清理。
- 字体已就绪时不再额外执行 ScrollTrigger.refresh。使用系统字体，无第三方字体下载。图片容器尺寸固定，背景不参与内容布局。
- 人物圆环静止时不持续更新，自动旋转仍需主动开启。水平轮播手势的局部非 passive wheel 监听保留，以支持水平拖动。

## 验证

- 生产构建通过，7 项 Node 测试通过：覆盖 60、90、120、144、165、240Hz 的 30fps 调度，暂停后恢复，以及桌面 / 4K / 移动尺寸预算。
- 浏览器资源记录确认首页未加载 Lightfall、原 JPEG、旧海报或旧视频；首图预加载命中。
- 完整学者视口下 Grainient 绘制增量为零；模拟 document.hidden 后两个背景绘制增量均为零。减少动态效果后 Lightfall 仅补绘一帧（14 个绘制调用）。
- 开始探索、人物切换、项目定位人物、悬浮磨砂导航、项目卡片入场完成状态、窄屏布局与无 WebGL 回退已检查。浏览器控制台无 error / warn。
- 1920、1280 与 390px 窗口无横向溢出。桌面截图为 1280×720 视口。

以上是文件字节、画布预算和行为验证，不是全设备帧率或公网加载时间保证。首页 opening 保留约 3.43 秒的设计节奏，LCP 会受有意的遮罩进场影响。实际设备 GPU 时间和公网指标应在最终展示电脑及部署环境复测。
